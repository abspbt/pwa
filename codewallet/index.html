GitHub Pages 與 PWA 部署指南

1. 專案檔案結構

部署至 GitHub Pages 前，請確保 Repository 包含以下檔案：

  • index.html (主程式畫面)
  • manifest.json (PWA 描述檔)
  • sw.js (Service Worker 離線快取)
  • .nojekyll (避免 GitHub Pages 誤用 Jekyll 處理)

2. 一鍵匯出 PWA 部署資產

點擊下方按鈕可直接下載 PWA 部署所需的設定檔：

3. GitHub Pages 部署 4 步驟

  1. 建立一個全新的 GitHub Repository（例: my-barcode-pwa）。
  2. 將 index.html、manifest.json、sw.js 與 .nojekyll 上傳至 Repository。
  3. 前往 Repository 的 Settings → Pages。
  4. Build and deployment 選擇 Deploy from a branch，Branch 選擇 main / root 並儲存。稍等 1 分鐘即可取得 PWA 專屬網址！
